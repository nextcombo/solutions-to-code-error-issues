\n        \n      
This issue is likely caused by multiple solves, where the previous solve failed. The Matlab version and the optimization package Cplex version do not match.
Here are the solutions provided: 👇👇👇
Check if the Matlab program is installed correctly and corresponds to its corresponding solvers such as yalmip and cplex/gurobi. Additionally, there are also cases where the high-level Matlab version does not match well with the solver.
